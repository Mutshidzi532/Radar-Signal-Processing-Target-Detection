# Radar-Signal-Processing-Target-Detection

Project Overview

This project uses MATLAB to simulate a simplified radar signal processing and target detection workflow. It explores how a target signal can be distinguished from noise using frequency domain analysis, threshold detection, Monte Carlo simulation, and receiver operating characteristic (ROC) analysis.

The project demonstrates the application of mathematical modelling, signal processing, and statistical analysis to a simulated radar scenario.

Objectives

* Generate a target signal contaminated by Gaussian noise.
* Apply Fast Fourier Transform (FFT) analysis to identify the dominant frequency.
* Implement a threshold-based target detector.
* Estimate detection and false alarm probabilities through Monte Carlo simulation.
* Evaluate how detection thresholds affect detector performance.
* Generate a ROC curve to compare detection performance.
* Examine the relationship between noise level and signal-to-noise ratio (SNR).

Tools and Technologies

* MATLAB
* Signal processing

Methodology

1. Signal Simulation

A sinusoidal target signal was generated and combined with Gaussian noise to represent a simplified noisy measurement.

2. Frequency-Domain Analysis

The Fast Fourier Transform was used to analyse the simulated signal and identify its dominant frequency component.

3. Threshold-Based Detection

A detection statistic based on the absolute signal amplitude was compared with a selected threshold to determine whether the simulated target was detected.

4. Detection Performance Evaluation

Monte Carlo trials were used to estimate the probability of detection and probability of false alarm under the selected simulation assumptions.

5. Threshold Analysis

Multiple detection thresholds were evaluated to examine the trade-off between detecting a target and generating false alarms.

6. ROC Analysis

A receiver operating characteristic curve was generated by plotting the estimated probability of detection against the probability of false alarm for different thresholds.

7. SNR Analysis

Theoretical signal-to-noise ratio was calculated for several noise levels to demonstrate how noise power affects signal quality.

Key Results

* The FFT analysis identified a dominant frequency of approximately 50 Hz in the simulated signal.
* The selected threshold detector detected the target in the example run.
* In one Monte Carlo experiment of 10,000 trials, the estimated probability of detection was 1.0000 and the estimated probability of false alarm was 0.0005.
* Threshold comparison illustrated how detector sensitivity changes with the selected threshold.
* ROC analysis provided a visual comparison of detection and false alarm performance.
* SNR calculations demonstrated the theoretical effect of changing noise power.

These results are specific to the chosen simulation parameters. They are not measurements of a real radar system or evidence of operational radar performance.

Limitations

This project is an educational simulation using a sinusoidal signal and Gaussian noise. It does not model a complete operational radar system. It excludes real radar hardware, antenna behaviour, propagation losses, clutter, interference, and realistic target echo generation.

The detection method is a simplified amplitude-threshold approach rather than a complete radar detection algorithm.

Estimated detection and false alarm probabilities depend on the simulation setup, number of trials, and chosen threshold.
