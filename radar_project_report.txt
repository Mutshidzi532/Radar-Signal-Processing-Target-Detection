RADAR SIGNAL PROCESSING AND TARGET DETECTION
============================================

Project objective:
Simulate a target signal, analyse its frequency, and evaluate threshold-based detection performance.

Simulation configuration:
Sampling frequency: 1000.00 Hz
Target frequency: 50.00 Hz
Target amplitude: 1.00
Noise standard deviation: 0.30
